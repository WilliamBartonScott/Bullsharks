# Brisbane Bullsharks Freediving Club

Website for the Brisbane Bullsharks Freediving Club.

## Live Site
[bullsharksfreediving.com](https://bullsharksfreediving.com)

## Tech Stack
- HTML, CSS
- Hosted on GitHub Pages
- Custom domain via Namecheap

## How to Update
1. Edit `index.html` in VS Code
2. Preview changes with Live Server (right-click → Open with Live Server)
3. When happy, deploy:
```bash
git add .
git commit -m "describe your change"
git push
```
Site updates within 60 seconds.
